Berkah POS - Admin Resmi

Schema LIVE app_config(key PRIMARY KEY, value JSONB) - global + device:<id>

(?) Apa: email akun Supabase Auth dengan membership owner/admin. Contoh: owner@domain.id. Jika kosong: operasi LIVE yang dilindungi RLS tidak bisa login.
(?) Apa: password akun admin untuk session Supabase Auth. Contoh: password akun owner/admin. Jika kosong: SAVE/LOAD LIVE gagal bila belum ada session aktif.
Belum ada operasi. Login admin diperlukan oleh RLS untuk licences dan app_config.

Fallback browser memakai localStorage dengan key global dan device:<device_id>. Tidak pernah gunakan service-role key di halaman publik GitHub Pages.
